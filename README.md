## 📌 Sobre o projeto

O **VR Automotive** é um projeto de desenvolvimento web criado para apresentar a empresa, destacar seus serviços e facilitar a comunicação com clientes.

O site possui uma interface moderna, com identidade visual inspirada no universo automotivo, utilizando tons escuros e detalhes em vermelho para transmitir sofisticação e personalidade.

O projeto foi desenvolvido pensando na experiência do usuário, na navegação intuitiva e na adaptação a diferentes dispositivos.

## ✨ Funcionalidades

- 🏠 Página inicial com apresentação da empresa.
- 🚘 Identidade visual personalizada para o segmento automotivo.
- 🔧 Seção dedicada aos serviços.
- 📱 Layout responsivo para diferentes tamanhos de tela.
- 💬 Botão de contato pelo WhatsApp.
- 🧭 Navegação intuitiva entre as seções.
- 🎨 Interface moderna com animações e elementos visuais.

## 🛠️ Tecnologias utilizadas

As principais tecnologias utilizadas no desenvolvimento foram:

- **React** — Construção da interface.
- **JavaScript** — Lógica e interatividade.
- **Vite** — Ferramenta de desenvolvimento e build.
- **CSS3** — Estilização e responsividade.
- **HTML5** — Estruturação do projeto.
- **Git e GitHub** — Versionamento e gerenciamento do código.

## 🚀 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/Barbara-larissa/vr-automotive.git
```

### 2. Acesse a pasta

```bash
cd vr-automotive
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm run dev
```

O Vite disponibilizará um endereço local para visualizar a aplicação no navegador.

### 5. Gerar versão de produção

```bash
npm run build
```
